Belajar Git

Git adalah sistem kontrol versi terdistribusi yang digunakan untuk melacak perubahan dalam kode sumber selama pengembangan perangkat lunak. Ini memungkinkan banyak pengembang untuk bekerja pada proyek yang sama tanpa mengganggu pekerjaan satu sama lain.

Perintah Dasar Git

  • git init: Menginisialisasi repositori Git baru.
  • git clone [url]: Mengkloning repositori dari URL tertentu.
  • git add [file]: Menambahkan file ke staging area.
  • git commit -m "[pesan]": Membuat commit dengan pesan tertentu.
  • git push: Mengirim perubahan ke repositori jarak jauh.
  • git pull: Mengambil dan menggabungkan perubahan dari repositori jarak jauh.
  • git status: Menampilkan status file di repositori.
  • git log: Menampilkan riwayat commit.
